1. REQUIRED DEPENDENCIES & PREREQUISITES
--------------------------------------------------------------------------------
Before running the project, make sure you have the following installed:

a. Java Development Kit (JDK 17 or higher):
   - Check if installed: 
     java -version
     javac -version
   - If not installed, download & install JDK 17+ from:
     https://www.oracle.com/java/technologies/downloads/
     (or OpenJDK: https://adoptium.net/)

b. MySQL Server / XAMPP:
   - Download & install XAMPP from: https://www.apachefriends.org/
   - Open XAMPP Control Panel and click "Start" for Apache and MySQL.

c. MySQL JDBC Driver (Connector/J):
   - The driver file 'mysql-connector-j-9.2.0.jar' must be inside the 'lib/' folder.
   - If missing, download it from:
     https://repo1.maven.org/maven2/com/mysql/mysql-connector-j/9.2.0/mysql-connector-j-9.2.0.jar
     and place it inside the 'lib/' directory of the project.

d. Git:
   - Check if installed: git --version
   - If not installed, download from: https://git-scm.com/

4. DATABASE SETUP (XAMPP / MYSQL)
--------------------------------------------------------------------------------
The system supports both databases; this checkout is configured for XAMPP/MySQL
in database/local.properties with db.type=mysql.
You can use EITHER MySQL (XAMPP) OR Microsoft SQL Server (SSMS), or switch freely between them:

>>> OPTION 1: Using MySQL / XAMPP (phpMyAdmin)
1) Open XAMPP Control Panel and start "Apache" and "MySQL".
2) Open your browser to: http://localhost/phpmyadmin
3) Go to the "SQL" tab (or click "Import").
4) Copy the entire contents of "database/text/mysql.txt" (or import "database/00_setup_mysql.sql")
   and click "Go".
   - This creates `faculty_management_db`, all 17 tables, and all seed data in one single step!
5) Keep "db.type=mysql" in "database/local.properties". The default XAMPP connection
   uses localhost:3306, username "root", and no password. If yours differs, update mysql.*.

>>> OPTION 2: Using Microsoft SQL Server (SSMS)
1) Open SQL Server Management Studio (SSMS).
2) Connect to your server (e.g., localhost, .\SQLEXPRESS, or (local)).
3) Open file "database/text/sqlserver.txt" (or "database/00_setup_sqlserver.sql").
4) Click "Execute" (F5).
   - This creates `faculty_management_db`, login `fms_user`, all 17 tables, and all seed data!
5) In "database/local.properties", leave:
   db.type=auto (or set db.type=sqlserver)

To switch databases, change db.type to "auto" or "sqlserver" and configure the
matching connection settings in database/local.properties.


5. COMPILE & RUN THE PROJECT
--------------------------------------------------------------------------------

>>> RECOMMENDED: Using Maven
mvn clean package
mvn exec:java -Dexec.mainClass="com.faculty.management.Main"

>>> OPTION A: Using PowerShell (VS Code Terminal)

1) Compile:
javac -cp "lib/*;resources" -d bin (Get-ChildItem -Recurse -Filter *.java src | ForEach-Object { $_.FullName })

2) Run:
java -cp "bin;lib/*;resources" com.faculty.management.Main

--- Or compile & run in a single command ---
javac -cp "lib/*;resources" -d bin (Get-ChildItem -Recurse -Filter *.java src | ForEach-Object { $_.FullName }); java -cp "bin;lib/*;resources" com.faculty.management.Main


>>> OPTION B: Using Command Prompt (cmd.exe)

1) Compile:
dir /s /b src\*.java > sources.txt
javac -cp "lib/mysql-connector-j-9.2.0.jar;resources" -d bin @sources.txt
del sources.txt

2) Run:
java -cp "bin;lib/mysql-connector-j-9.2.0.jar;resources" com.faculty.management.Main


>>> OPTION C: Using IDE (IntelliJ IDEA / Eclipse / VS Code)
1) Open the project folder in your IDE.
2) Add the JAR file 'lib/mysql-connector-j-9.2.0.jar' to Project Libraries / Classpath.
3) Set Project SDK to Java 17+.
4) Right-click 'src/com/faculty/management/Main.java' -> Run.
