ROLE & PURPOSE:
- The Data Access Object (DAO) layer isolates direct SQL database interactions from the rest of the application.
- Uses JDBC (Java Database Connectivity) with `PreparedStatement` to prevent SQL injection vulnerabilities.
- Handles differences between MySQL and Microsoft SQL Server seamlessly via `DatabaseConnection` singleton.
