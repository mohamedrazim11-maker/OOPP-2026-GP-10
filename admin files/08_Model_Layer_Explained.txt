ROLE & PURPOSE:
- Represents the core Object-Oriented domain entities for Member 1.
- Demonstrates key lecture principles: Inheritance, Polymorphism, Abstraction, and Encapsulation.

----------------------------------------------------------------------------------------------------
PART 1: Admin.java & User.java (Inheritance & Polymorphism)
----------------------------------------------------------------------------------------------------
User.java:
- Declared as `public abstract class User`: Cannot be instantiated directly; serves as an abstract
  blueprint for all system user roles (Admin, Lecturer, TechnicalOfficer, Undergraduate).
- Fields (Encapsulation): `userId`, `username`, `password`, `email`, `firstName`, `lastName`,
  `contactNo`, `profilePic`, `status`, and `role`. All fields are `private` or `protected` with public getters/setters.
- Polymorphic Abstract Methods:
  - `public abstract String getRoleTitle();`
  - `public abstract String getDashboardGreeting();`
- Concrete Shared Methods:
  - `public String getFullName()`: Concatenates `firstName + " " + lastName`.

Admin.java:
- Declared as `public class Admin extends User`: Direct concrete subclass representing Administrator.
- Constructors:
  - Parameterized constructor: Explicitly invokes `super(userId, username, password, email, firstName, lastName, role, contactNo, profilePic, status)` to initialize inherited base properties.
- Polymorphic Method Overriding:
  - `@Override public String getRoleTitle()`: Returns `"System Administrator"`.
  - `@Override public String getDashboardGreeting()`: Returns `"Welcome back, Administrator " + getFullName() + "!"`.
  - At runtime, calling `user.getRoleTitle()` on an `Admin` reference dynamically dispatches to this method.

PART 2: Course.java (Encapsulation & Academic Business Calculations)
----------------------------------------------------------------------------------------------------
ROLE & PURPOSE:
- Models an academic course module within the Faculty of Technology.
- Encapsulates course identification, credit ratings, contact hours, and department affiliations.

DETAILED LINE-BY-LINE EXPLANATION:
- Fields:
  - `private int courseId`: Primary key in relational database.
  - `private String courseCode`: Unique academic code (e.g., "ICT2132").
  - `private String courseName`: Full descriptive title (e.g., "Object Oriented Programming Practicum").
  - `private int creditValue`: Academic credit weighting (typically 2 to 4 credits).
  - `private int theoryHours`: Total lecture hours across the semester (e.g., 30 hours).
  - `private int practicalHours`: Total laboratory/practical hours (e.g., 60 hours).
  - `private String department`: Assigned academic department.
  - `private String semester`: Semester offering ("Semester 1" or "Semester 2").
  - `private String description`: Syllabus curriculum description.
- Constructors:
  - Parameterized constructor accepting all 9 fields.
  - Overloaded constructor without `courseId` for newly created courses before database insertion.
  - Overloaded constructor with code, name, and credits for rapid initialization.
- Encapsulated Methods:
  - Full set of public getters and setters with validation.
  - `public int getTotalContactHours()`: Computes `theoryHours + practicalHours`.
  - `public boolean hasPracticalComponent()`: Returns `practicalHours > 0`.
  - `@Override public String toString()`: Returns `courseCode + " - " + courseName` (used directly in JComboBox renderers).

PART 3: Notice.java (Announcement Entity)
----------------------------------------------------------------------------------------------------
ROLE & PURPOSE:
- Represents an official circular or announcement published by faculty administration.

DETAILED LINE-BY-LINE EXPLANATION:
- Fields:
  - `private int noticeId`: Primary key.
  - `private String title`: Announcement headline.
  - `private String content`: Complete announcement text body.
  - `private String category`: Category string (`GENERAL`, `ACADEMIC`, `EXAMINATION`, `TIMETABLE`).
  - `private String priority`: Urgency rating (`NORMAL`, `URGENT`, `INFO`).
  - `private String postedBy`: Publisher attribution (e.g., "Dean's Office").
  - `private LocalDate postedDate`: Standard `java.time.LocalDate` date of publication.
- Constructors:
  - Full parameterized constructor with ID and date.
  - Overloaded constructor without ID for drafting new notices.
- Utility Methods:
  - `public String getFormattedDate()`: Formats date using `DateTimeFormatter.ofPattern("yyyy-MM-dd")`.
  - `public boolean isUrgent()`: Returns `"URGENT".equalsIgnoreCase(priority)`.
  - Getters and setters for all encapsulated fields.

PART 4: Role.java (Authorization & Permissions)
----------------------------------------------------------------------------------------------------
ROLE & PURPOSE:
- Represents user roles and system privileges within the Role-Based Access Control (RBAC) model.

DETAILED LINE-BY-LINE EXPLANATION:
- Constants:
  - `public static final String ADMIN = "ADMIN";`
  - `public static final String LECTURER = "LECTURER";`
  - `public static final String TECHNICAL_OFFICER = "TECHNICAL_OFFICER";`
  - `public static final String UNDERGRADUATE = "UNDERGRADUATE";`
- Fields:
  - `private int roleId`: Primary key (1 = Admin, 2 = Lecturer, 3 = Technical Officer, 4 = Undergraduate).
  - `private String roleName`: Role identifier string.
  - `private String description`: Privilege scope description.
- Methods:
  - Getters, setters, and `toString()` returning `roleName`.
